# Native evidence interface

`authmatrix.result/v1` is a **local immutable format** for eventual ProofGraph adapters. The adapter must explicitly transform the schema; this RC does *not* import any shared Go code from other tools. `evidence_status: observed` means a supplied status was observed by an operator, not that AuthMatrix verified the response against a live service. `potential-bypass` is a hypothesis/inference pending independent human verification. `match` means only observed status matched the supplied expectation. `inconclusive` means insufficient evidence. `scope_sha256` and `input_sha256` preserve privacy-safe correlation/provenance but should not be treated as cryptographic permission proof. Future adapters must not upgrade hypotheses to `confirmed` without separately signed/human-validated evidence.
